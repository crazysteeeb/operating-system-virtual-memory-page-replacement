# Virtual Memory Page Replacement Simulator

A C++ simulation demonstrating virtual memory paging and page replacement concepts commonly used in operating systems.

## Overview

This project simulates how operating systems manage virtual memory and page replacement behavior.

The simulator demonstrates:
- Paging behavior
- Memory management concepts
- Virtual memory simulation
- Systems programming fundamentals

## Features

- Virtual memory simulation
- Paging behavior
- Page replacement logic
- Memory management concepts
- Multi-file C++ project structure

## Technologies Used

- C++
- Linux
- Visual Studio Code

## Concepts Demonstrated

- Virtual memory
- Page replacement
- Memory management
- Systems programming
- Operating systems fundamentals

## How to Compile

```bash
g++ main.cpp pager.cpp -o simpager
```

## How to Run

```bash
./simpager
```
